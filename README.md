# loss-management

Energy Loss Management System (ELMS) demo presentation for EDC, by OONE Power Technology.

## Presentation

`index.html` is the self-contained HTML slide deck (16 slides, English). Fonts and images are embedded, so it works offline.

Open the file in a browser. Controls:

- Click the right side of a slide for next, the left side for back (like Canva)
- Arrow keys / Space: next and previous slide
- `F`: full screen
- `T`: switch light / dark mode
- `L`: switch English / Khmer (language button in the bottom bar: hover or tap it to pick English or ខ្មែរ). English is the default; add `?lang=km` to the link to open in Khmer.
- Swipe on touch screens
